# Free web access alongside paid mobile Premium

The planned web version prioritises useful free study access and organic reach, with mobile sales secondary. Provide free web access while retaining the existing paid Premium model on Android and iOS; this deliberately accepts that learners may choose free web mock tests instead of buying mobile Premium. This product direction was agreed on 19 October 2026; the [launch plan](../growth/web-launch.md) records scope and release gates. Implementation has not started.

Free web access must remain distinct from paid ownership in product language and analytics. Track mobile revenue impact explicitly, and describe the platform difference honestly rather than implying that web usage establishes a purchase or a mobile entitlement.
